# Release Notes: v0.4.2

**Release Date:** 2026-10-14

## Overview

Traffic2OpenAPI v0.4.2 is a maintenance release that fixes path-pattern exclusion in the Python Playwright adapter.

The Go packages are unchanged from v0.4.1.

## Fixed

- Python Playwright adapter: `exclude_path_patterns` now match anywhere in the request path, consistent with the TypeScript adapter's `excludePathPatterns`. Previously a pattern such as `\.js$` never matched because matching was anchored at the start of the path.

## Tests

- Correct the Playwright adapter test mock so `Request.method` is a property, matching Playwright's API
