# Release Notes: v0.4.1

**Release Date:** 2026-10-14

## Overview

Traffic2OpenAPI v0.4.1 is a maintenance release. It adapts the HAR converter to `github.com/chromedp/cdproto` v0.158 and refreshes dependencies.

There are no behavior changes for users of HAR conversion, inference, or OpenAPI generation.

## Fixed

- HAR converter handles `har.Content.Text` as `[]byte`. In cdproto v0.158, base64-encoded response content is decoded during unmarshal, so the converter no longer decodes it a second time.
